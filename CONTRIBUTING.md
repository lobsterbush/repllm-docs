# Contributing to repllm

Thanks for taking a look. I’d be glad of the help, and I’d be especially
glad to hear where the package gets something wrong.

## Reporting bugs

Open an issue at <https://github.com/lobsterbush/repllm/issues> and
include a minimal reproducible example, the output of
[`sessionInfo()`](https://rdrr.io/r/utils/sessionInfo.html), and the
version you’re on from `packageVersion("repllm")`.

If a check passed when you think it should have failed, that’s the most
useful kind of report I can get. A validation tool that quietly says
everything is fine is worse than no tool, so please tell me.

## Suggesting features

Open an issue describing what you want to do and why. The package has a
narrow scope on purpose: generating experimental stimuli with a model,
and validating them before they go into the field. Anything to do with
talking to a model, managing credentials, batching, or cost accounting
belongs in [ellmer](https://ellmer.tidyverse.org/) instead, and I’d
rather point you there than duplicate it here.

## Pull requests

Fork the repository and branch from `main`.

Match the code style you find. Exported functions are `snake_case`,
internal helpers are `.snake_case` with a leading dot and carry
`@keywords internal` plus `@noRd`. Every exported function needs
`@param`, `@return`, `@export`, and `@examples`.

Add tests with `testthat`. Nothing in the suite requires an API key and
I’d like to keep it that way, so use the bundled datasets or mock the
ellmer call with `local_mocked_bindings()`. There are examples of both
in `tests/testthat/`.

If you’re fixing a bug, please add a test that fails before your change
and passes after it, and say in a comment what the failure mode was.
Several of the tests in `test-regressions.R` are written that way and
they’ve earned their keep.

Then run:

``` r
devtools::document()
devtools::test()
devtools::check()
```

`check()` should come back with 0 errors, 0 warnings, and 0 notes.
Update `NEWS.md` while you’re there.

Please don’t edit `NAMESPACE` or anything in `man/` by hand. Both are
generated by
[`devtools::document()`](https://devtools.r-lib.org/reference/document.html).

## Code of conduct

Be kind. That’s the whole of it.
